# skield.beta

A badge studio for creating beautiful, shield.io-style badges in seconds.

`skield.beta` is a lightweight, simple tool for making badges without wrestling with raw shield.io parameters. It helps you design a badge, preview it instantly, and copy the Markdown or HTML snippet you need.

## Why skield.beta?

- Fast badge generation for GitHub repos, docs, and product pages
- Live preview while you edit label, message, colors, and style
- Simple exports for Markdown, HTML, and shield.io URL output
- Clean design focused on speed and clarity

## Features

- Edit badge label and message
- Choose colors and badge style
- Preview the badge live
- Copy the generated shield.io URL
- Copy Markdown and HTML snippets
- Built to work as a starter project for a future badge builder app

## Example

```md
![build](https://img.shields.io/badge/build-passing-brightgreen)
```

## Run locally

Open `index.html` directly in a browser, or serve the project with any static file server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
